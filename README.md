# Responsive Design - Basic Media Queries

Course: **Advanced Styling with Responsive Design** (University of Michigan / Coursera)  
Author: `kiennguyen123-code`

## Overview
This responsive webpage demonstrates three distinct layouts using mobile-first CSS media queries:
1. **Mobile View (< 772px):** Single-column layout where divs span 100% width, stacked vertically (1 div across).
2. **Tablet View (≥ 772px):** Two-column layout where divs take 45% of the viewport width (`display: inline-block; width: 45%;`) and images have a maximum height of 30% of the viewport height (`max-height: 30vh;`).
3. **Desktop / Large Screen View (≥ 998px):** Three-column layout where divs take 30% of the viewport width (`width: 30%;`).
